The CONNEX Agent transcends single-turn prompt-response interactions. It autonomously deconstructs complex business intents, coordinates with Brain X knowledge assets, and leverages Studio VFS to deliver verified, high-density business deliverables.

## 1. High-Precision Sub-Channel Prompting

To prevent unnecessary token expenditure and ensure deterministic reasoning, utilize targeted context bindings:

<CardGroup cols={2}>
  <Card title="Context Attachment (VFS Binding)" icon="folder-git-2">
    Click the [+] button in the prompt area or select files in the VFS explorer to attach a single folder badge, transmitting only authoritative chunk references.
  </Card>
  <Card title="Target Brain Selection" icon="dna">
    When specific domain expertise (legal, financial, tax, engineering) is required, select an enterprise Brain persona from the selector dropdown.
  </Card>
</CardGroup>

## 2. 18-Visual Dynamic Analytical Charts (Recharts)

The Agent renders complex quantitative analyses into interactive, responsive visualization widgets directly within the chat stream:

| Visualization Category | Supported Chart Types | Enterprise Applications |
| :--- | :--- | :--- |
| **Trend & Time-Series** | Line, Area, Stacked Area | Revenue run-rate, monthly API throughput, customer churn |
| **Comparative & Ranking** | Bar, Horizontal Bar, Grouped Bar | Business unit performance, product line cost variance |
| **Composition & Split** | Pie, Donut, Radial Bar | Portfolio asset allocation, customer demographic share |
| **Multi-Dimensional Matrix** | Radar, Scatter, Bubble | Vendor risk assessment, technology stack fit scoring |

## 3. Multimodal In-Stream Viewers

Preview attached files and synthesized artifacts directly inside the workspace without third-party desktop tools:
- **Code Viewer**: Syntax highlighting for 20+ programming languages with one-click copy and line numbering.
- **PDF Viewer**: High-performance canvas renderer supporting page jumping, zoom controls, and full-text search.
- **CSV & Markdown Viewers**: Instant tabular rendering with column-sorting and responsive data filtering.
