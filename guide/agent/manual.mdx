## 1. 고효율 서브채널 프롬프팅 기법

불필요한 토큰 소비를 방어하고 최상의 응답 품질을 도출하기 위해 정밀한 서브채널 프롬프팅을 지원합니다.

## 2. 18종 동적 분석 차트 (Recharts Engine)

에이전트는 데이터 집계 결과를 텍스트 표에 그치지 않고, 대화창 내부에서 인터랙티브 반응형 차트로 실시간 렌더링합니다.

| 차트 카테고리 | 지원 시각화 타입 | 대표 활용 시나리오 |
| :--- | :--- | :--- |
| **추세 및 시계열** | Line, Area, Stacked Area | 월별 매출 추이, 서버 트래픽 변동률 |
| **비교 및 랭킹** | Bar, Horizontal Bar, Grouped Bar | 사업부별 실적 비교, 비용 절감 순위 |
| **비율 및 분할** | Pie, Donut, Radial Bar | 포트폴리오 자산 배분, 고객 세그먼트 구성비 |
| **다차원 상관분석** | Radar, Scatter, Bubble | 기술 스택 적합도 평가, 벤더 리스크 분석 |

## 3. 멀티포맷 인라인 뷰어

채팅창 내부에서 첨부되거나 생성된 결과물을 별도 외부 프로그램 없이 즉시 열람할 수 있습니다.
- **Code Viewer**: 20개 이상 프로그래밍 언어의 구문 강조(Syntax Highlighting) 및 복사 지원
- **PDF Viewer**: 페이지 점프, 확대/축소, 텍스트 검색을 지원하는 고성능 렌더러
- **CSV & Markdown**: 대용량 데이터셋의 즉각적인 소팅 및 표 뷰 지원
