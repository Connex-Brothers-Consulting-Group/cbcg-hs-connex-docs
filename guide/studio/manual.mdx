## 1. 7대 원자적 파일 뮤테이션 (Atomic Mutations)

파일 조작 중 네트워크 오류가 발생하더라도 데이터 무결성이 손상되지 않도록 트랜잭션 방식으로 처리됩니다.

| 동작명 | 설명 | 캐시 무효화 | 전파 방식 |
| :--- | :--- | :--- | :--- |
| `create_folder` | 신규 디렉터리 생성 | 즉시 (`user_id`) | SSE `VFS_CHANGED` |
| `upload_file` | 대용량 이진 및 텍스트 파일 수집 | 즉시 (`user_id`) | SSE `VFS_CHANGED` |
| `delete_item` | 파일 및 하위 폴더 재귀 삭제 | 즉시 (`user_id`) | SSE `VFS_CHANGED` |
| `rename_item` | 파일명 및 메타데이터 원자적 변경 | 즉시 (`user_id`) | SSE `VFS_CHANGED` |
| `move_items` | 대규모 배치 교차 폴더 이동 | 즉시 (`user_id`) | SSE `VFS_CHANGED` |
| `move_item` | 단일 파일 위치 변경 | 즉시 (`user_id`) | SSE `VFS_CHANGED` |
| `clone_file` | 원본 불변 복제본 생성 | 즉시 (`user_id`) | SSE `VFS_CHANGED` |

## 2. 브라우저 인라인 에디터

Studio 내장 에디터를 통해 로컬 IDE 없이도 클라우드 상에서 마크다운, 코드, 설정 파일을 직접 편집할 수 있습니다.
- **자동 저장 및 변경 감지**: 작성 중인 내용이 로컬 버퍼에 안전하게 캐싱되어 예기치 못한 브라우저 종료 시에도 복구됩니다.
- **실시간 프리뷰(Live Preview)**: 마크다운 및 KaTeX 수식이 오른쪽 패널에 60 FPS로 즉시 렌더링됩니다.
