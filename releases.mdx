# Release History & Roadmap

Official changelog and version milestones for CONNEX Cloud OS.

## Version 3.8.0 (2026.10.05) - Current Stable

<Update label="V3.8.0" description="Official GA Release — October 05, 2026">
### 🚀 Key Improvements & Highlights
- **Universal 2x1 Grid Layout Architecture**: Standardized symmetrical 2x1 grid system eliminating viewport shifts during panel transitions
- **3-Pillar Resources Hub Transformation**:
  - `01. Live Support`: Dedicated 2x2 grid for 4 specialized support inboxes
  - `02. Communication`: Official platform announcements, release notes, and GKE multi-region SLA telemetry
  - `03. Documentation Center`: Direct deep-linking to Mintlify SSOT knowledge portal
- **SWR Zero-Flicker Hydration Protocol**: Eliminates content flickering during background cache revalidation
- **W3C `@layer` 3-Tier CSS Standardization**: Zero `!important` declarations across all global design tokens
</Update>
