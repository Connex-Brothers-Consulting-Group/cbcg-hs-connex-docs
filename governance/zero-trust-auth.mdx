# 제로 트러스트 인증 (Zero-Trust Auth)

CONNEX Cloud OS는 자체 데이터베이스에 비밀번호를 저장하지 않으며, 전 세계 보안 표준인 Firebase Auth 및 Google Identity를 통해 인증을 위임합니다.

<Steps>
  <Step title="120초 단일 사용 티켓 핸드셰이크">
    크로스 도메인 SSO 리다이렉션 시 재전송 공격(Replay Attack)을 방지하기 위해 Redis에 매핑된 UUIDv4 티켓을 사용하며, 1회 교환 즉시 소각(Burn)됩니다.
  </Step>
  <Step title="수학적 토큰 레벨 권한 검증">
    사용자의 역할(`role`), 관할 국가(`home_country`), 관리자 권한 등이 JWT ID 토큰 클레임에 서명되어 주입되므로, 다운스트림 마이크로서비스는 DB 조회 없이 헤더 검증만으로 sub-1ms 인가를 수행합니다.
  </Step>
  <Step title="7대 플랫폼 표준 역할 (RBAC)">
    `super_admin`, `founders`, `devops`, `bizops`, `demo_cx`, `customer_b2b`, `customer_b2c`의 7대 권한 계층을 엄격히 통제합니다.
  </Step>
</Steps>
