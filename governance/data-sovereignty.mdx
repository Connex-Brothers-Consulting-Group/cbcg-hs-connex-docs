# 멀티 리전 데이터 주권 (Data Sovereignty)

CONNEX Cloud OS는 국가별 개인정보보호 법률을 엄격히 준수하기 위해 **리전 간 물리적 데이터베이스 완전 격리 원칙**을 시행합니다.

<CardGroup cols={2}>
  <Card title="대한민국 관할 (PIPA 준수)" icon="landmark">
    대한민국 법률에 따라 모든 사용자 계정, 세션, VFS 파일 및 대화 내역이 **서울 리전(asia-northeast3)** 전용 데이터베이스에 영구 고정 보관되며 국외 이전을 엄격히 차단합니다.
  </Card>
  <Card title="미국 및 글로벌 관할 (CCPA 준수)" icon="globe">
    미국 및 글로벌 이용자의 데이터는 **아이오와 리전(us-central1)** 전용 인프라에 격리 보관되며, SOC 2 보안 기준을 준수합니다.
  </Card>
</CardGroup>

<Warning>
  사용자는 회원가입 시 본인의 거주 국가 관할 리전을 자발적으로 선택하며, 선택된 리전은 변경되지 않고 엄격하게 고정 유지됩니다.
</Warning>
