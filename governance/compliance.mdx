# 규정 준수 및 보안 감사 (Compliance)

CONNEX Cloud OS 및 HybridSphere 생태계는 글로벌 최고 수준의 보안 컴플라이언스 기준을 준수합니다.

<AccordionGroup>
  <Accordion title="SOC 2 Type II 이중 PR 릴리즈 게이트 (CC8.1/CC8.2)">
    모든 애플리케이션 코드 및 인프라 배포는 인간 관리자(HITL)의 소스 PR 승인과 ArgoCD 선언적 매니페스트 PR 승인을 거쳐야만 배포되는 엄격한 분리 통제를 따릅니다.
  </Accordion>
  <Accordion title="정적 키(JSON Key) 영구 금지 (Workload Identity)">
    소스코드나 클라우드 환경에 정적 GCP 서비스 어카운트 JSON 키를 저장하는 행위를 영구 금지하며, GKE Workload Identity를 통해서만 임시 권한을 획득합니다.
  </Accordion>
  <Accordion title="Cloud Armor WAF 및 DDoS 방어">
    GKE 외부 L7 Gateway 전면에 Cloud Armor WAF 보안 정책을 적용하여 비정상 트래픽 및 웹 공격을 원천 차단합니다.
  </Accordion>
</AccordionGroup>
