## Developer Hub & Model Context Protocol (MCP)

Developers can integrate with CONNEX using modern standard interfaces:
- **Model Context Protocol (MCP)**: Connect IDEs and AI agents directly to CONNEX tools ([MCP Specifications](https://docs.connex.hybridsphere.io/developers/mcp-server-spec)).
- **Public REST & WebSocket Protocol**: Real-time streaming token exchange and bidirectional event streams ([API Reference](https://docs.connex.hybridsphere.io/developers/authentication-api)).
- **Webhooks**: Event-driven notifications for CoWorx channel events and workflow completions.
