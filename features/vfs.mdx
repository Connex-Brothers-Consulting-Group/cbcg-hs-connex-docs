# Virtual File System (VFS)

The CONNEX Virtual File System (VFS) securely manages cloud documents in structured hierarchical folders, tightly integrated with real-time agent reasoning contexts.

<Steps>
  <Step title="Document Ingestion & Parsing">
    Drag and drop PDF, Word, Markdown, CSV, and code files directly into your isolated project directory.
  </Step>
  <Step title="3-Tier Cache Invalidation">
    All 7 mutation operations (create, upload, delete, rename, move, copy, clone) trigger instant L2 Redis cache eviction and SSE `VFS_CHANGED` broadcasts across all active client sessions.
  </Step>
  <Step title="Single-Badge Context Binding">
    Select individual files or full directory badges to inject authoritative grounding context directly into your AI prompt header.
  </Step>
</Steps>
