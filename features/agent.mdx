# CONNEX AI Agent

CONNEX Agent is an autonomous reasoning engine designed to execute complex data synthesis, code generation, strategic analysis, and executive report authoring.

<Tabs>
  <Tab title="Deep Reasoning">
    Leverages flagship multimodal LLM models to perform multi-step planning, tool chaining, and structured analytical synthesis.
  </Tab>
  <Tab title="Dynamic Artifacts">
    Renders interactive code sandboxes, structured Markdown briefs, dynamic Recharts visualizations, and Mermaid workflow diagrams in real time.
  </Tab>
  <Tab title="Grounded Citations">
    Directly anchors statements to source files using explicit chunk citations (`[ref:filename#section]`), eradicating speculative hallucinations.
  </Tab>
</Tabs>
