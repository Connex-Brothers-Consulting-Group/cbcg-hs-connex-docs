# CONNEX AI Agent

CONNEX Agent는 복잡한 데이터 분석, 코드 생성, 보고서 작성 및 전략적 의사결정을 지원하는 자율형 인공지능 에이전트입니다.

<Tabs>
  <Tab title="심층 추론 (Deep Reasoning)">
    Gemini 최신 플래그십 모델을 기반으로 다단계 사고 체계와 도구 호출을 수행하여 복잡한 비즈니스 문제를 해결합니다.
  </Tab>
  <Tab title="동적 아티팩트 (Artifacts)">
    실행 가능한 코드 블록, 마크다운 보고서, 인터랙티브 차트 및 SVG 다이어그램을 실시간 렌더링합니다.
  </Tab>
  <Tab title="근거 기반 인용 (Grounded Citations)">
    VFS 문서와 연동하여 출처(`[ref:filename#section]`)가 명확한 환각 없는 답변만을 제공합니다.
  </Tab>
</Tabs>
